# Support

Start with the [user guide](https://iller7.github.io/type-as-you-speak/usage.html), [installation](https://iller7.github.io/type-as-you-speak/install.html) and [troubleshooting](https://iller7.github.io/type-as-you-speak/troubleshooting.html) pages. Documentation lives in `docs/` and GitHub Pages so changes are reviewed with the code; we do not maintain a second wiki.

Use [issue forms](https://github.com/iller7/type-as-you-speak/issues/new/choose) for reproducible bugs, installation problems and feature requests. Include the app version, install method, OS/distro, desktop/session, model and synthetic reproduction. Linux is the current desktop target; macOS/Windows and cloud dictation are planned, not released features.

Never attach private speech, recordings, transcripts, hotwords, credentials or unreviewed logs. Use public/synthetic examples and redact diagnostics. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in public issues. Conduct concerns go to [faizal.sahebdin@gmail.com](mailto:faizal.sahebdin@gmail.com); see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
