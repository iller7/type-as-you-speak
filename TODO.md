## Project principles

- Build for Linux desktop users first, with a measured path to macOS and Windows.
- Support development with a local LLM on Kubuntu. Do not require a cloud LLM provider, API key, paid coding assistant or cloud inference service.
- Prefer established, maintainable practices that fit this app. Record the reason and trade-offs before adopting another project's structure or tooling.
- Use GitHub Free and free hosting as the baseline. Account for runner usage, artifact retention and hardware limitations.
- Keep raw speech and private user data out of logs, repositories, issues and CI artifacts.
- Keep Markdown prose naturally wrapped and documentation concise.
