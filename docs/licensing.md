# Licensing and commercial options

The current public first-party source is **AGPL-3.0-only**, meaning GNU Affero General Public License version 3. The version is fixed explicitly; a commercial exception or future licence change requires a separate decision. [LICENSE](https://github.com/iller7/type-as-you-speak/blob/master/LICENSE) contains the unmodified official terms.

AGPL permits commercial activity. It requires corresponding source and the applicable notices when conveying covered software, and a source offer to users interacting remotely with a modified version over a network where section 13 applies. It permits competing compliant forks and private local modifications; it does not grant exclusivity to the maintainer. See the [GNU explanation](https://www.gnu.org/licenses/why-affero-gpl.html).

For different permissions, see [commercial licensing enquiries](https://github.com/iller7/type-as-you-speak/blob/master/COMMERCIAL.md). An alternative agreement can cover only rights the copyright holder controls. No commercial contract, contributor rights grant, paid edition or cloud service is created by publishing that page.

| Bundled ydotool                                  | Upstream AGPL terms, notices and source archive; not relicensed as proprietary by this project |
| Python/native dependencies, including Qt         | Their own notices and licences; review the actual wheel/native package contents                |
| Model weights and audio fixtures                 | Per-model/per-fixture terms and provenance; never assume the app licence covers them           |

## Contributions and commercial rights

Contributions to the public core are received under its public licence. This does not itself give the maintainer permission to sell proprietary exceptions to someone else's contribution. Before accepting outside code into an alternatively licensed edition, establish the necessary written permissions or exclude that code. Contributor agreement and third-party/model/package compliance work remain tracked in [the licensing review](https://github.com/iller7/type-as-you-speak/issues/10).

The public licence decision is approved; the broader component audit remains open. Keep an accurate inventory and source/notices with distributed binaries. This guide describes project policy and does not replace the licence text or a negotiated commercial agreement.
